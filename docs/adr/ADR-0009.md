# ADR-0009: EPIC-04.04 — Validación Ib vs Iz + auto-sugerencia de sección (no vinculante)

## Estado
Aceptado (actualizado)

## Contexto
Con EPIC-04.01 (cargas agregadas) y EPIC-04.03 (tablas nominales v0), ya existe:
- Potencia downstream por feeder (kVA/kW)
- Catálogo nominal con ampacidad (Iz) por cable (AEA ampacity)
- Configuración de cable desde Network DSL (material, aislación, método, arrangement, parallel, grouped)

Se requiere iniciar el dimensionamiento en modo **validación** pero habilitar una **auto-sugerencia** reproducible.

## Decisión
Se implementa EPIC-04.04 como:
1) Validador Ib vs Iz (con evidencia)
2) Auto-sugerencia de sección mínima que cumple (no vinculante)
3) Materialización de artifacts reproducibles

Reglas:
- Corriente 3φ desde kVA:
  Ib = kVA*1000 / (sqrt(3)*Vll)
- Reserva configurada:
  Ib_design = Ib * (1 + reserve_pct/100)
- Paralelos (ternas en paralelo):
  Ib_per_cable = Ib_design / parallel
- Selección (sugerida):
  sección mínima tal que Iz >= Ib_per_cable

Artifacts:
- sizing_report.json / sizing_report.md
- cable_schedule.json / cable_schedule.md
- selected_wires.json

## Consecuencias
- Se habilita trazabilidad completa del criterio de selección.
- La selección sigue siendo “sugerida” (no coordina protección ni caída de tensión).
- grouped queda registrado para incorporar derating completo (k_group/k_temp/k_soil) en un siguiente sprint.
